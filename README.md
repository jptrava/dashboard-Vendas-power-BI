## 📌 Sobre o Projeto

Desenvolvimento de um painel interativo de Business Intelligence focado na análise de performance de vendas de produtos eletrônicos. O objetivo principal foi criar uma visão centralizada para monitoramento de KPIs e identificação de tendências de mercado, facilitando a tomada de decisão baseada em dados.

![Preview do Dashboard](caminho-da-sua-imagem.png)

## 🛠️ Ferramentas e Tecnologias

* **Microsoft Power BI:** Utilizado para a construção dos gráficos, interatividade e visualização final.
* **Power Query:** Essencial para o processo de ETL (Extração, Transformação e Carregamento), garantindo a limpeza e tratamento da base de dados.
* **DAX (Data Analysis Expressions):** Criação de medidas calculadas complexas para análises temporais e comparativas.
* **Figma:** Utilizado para a prototipação do layout e criação do background, garantindo uma interface amigável e profissional.

## 📊 O que foi analisado (Destaques)

O dashboard foi estruturado para responder a perguntas de negócio específicas:

* **Visão Macro:** Monitoramento de KPIs vitais como Faturamento Total (64Mi+), Volume de Vendas e identificação da Marca Líder (Rihappy).
* **Análise Geográfica:** Utilização de visualização *Tree Map* para mapear a concentração de vendas, evidenciando a predominância do mercado na América do Norte.
* **Mix de Produtos:** Rankeamento dos itens mais populares através de gráficos de barras, com destaque para a performance do *Headphone Bluetooth X450*.
* **Tendência Temporal:** Análise da variação do volume de vendas anual (2022, 2023, 2024) utilizando gráfico de funil para facilitar a visualização de quedas ou crescimentos.

## 💡 Principais Aprendizados

Durante a construção deste dashboard, pude aprimorar meus conhecimentos técnicos e analíticos:

* **Modelagem de Dados:** Aplicação prática do *Star Schema* (Esquema Estrela) para otimizar a performance do relatório.
* **Data Storytelling:** Aplicação de princípios de design e narrativa de dados para tornar a informação acessível a gestores não-técnicos.
* **Design de Interface:** A escolha estratégica das cores e a disposição dos cartões foram pensadas para guiar o olhar do usuário das informações gerais (macro) para as específicas (micro).
